## Neden ayrı bir tanıtım deposu?

Programın kaynak kodu **özel (private)** depoda durur — GitHub Pages ücretsiz planlarda yalnız
**herkese açık** depolarda çalıştığı için kod herkese açılmadan paylaşılabilir bir adres ancak böyle verilir:
bu depo yalnız tanıtım metni ve ekran görüntülerini taşır, **hiçbir kaynak kod burada yoktur**.

## Sayfa içeriği

1. ÜSTAD madalyon amblemi + kategori rozeti (MUHASEBE) + özellik etiketleri
2. "Bu program ne yapar?" kartları (aylık ücret yok · çevrimdışı · PBKDF2 · kurulum istemez)
3. **19 modülün numaralı tam listesi**
4. **24 gerçek ekran görüntüsü** (tıklayınca büyüyen ışık kutusu, kartlarda 3B eğilme efekti)
5. **ÜSTAD KASA bölümü:** karşılaştırma tablosu (8091 / 8092) + 8 şatafat ekranı
6. Nasıl çalışır (aç · gir · kaydet · çıktı al)
7. **Dürüst sınırlar** (OCR kapalı · PDF için Word gerekir · e-Fatura yok · APK yok · ağ modu HTTP)
8. Linkler (bu sayfa herkese açık · kaynak kodlar özel)

## Sayfayı güncelleme

`index.html` elle düzenlenir (tek dosya, kütüphanesiz). Yeni ekran görüntüsü eklemek:
dosyayı `ekran/` klasörüne koy → `index.html` içindeki `<figure class="kare">` bloğunu kopyala →
`commit` + `push`. GitHub Pages 1-2 dakikada kendini yeniler.
